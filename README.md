# QR-DINE
A complete digital dining solution that allows hotel guests to order food from their tables by scanning a QR code. The kitchen staff receives real-time orders through a dedicated mobile app.

## ✨ Features

### Guest Web App
- 🚫 No app download - works in any browser
- 🍕 Digital menu with categories
- 🛒 Add to cart with real-time total
- ✅ Instant order confirmation
- 📊 Track order status

### Kitchen App
- 🔔 Real-time order notifications
- 📋 View and manage orders
- 🏷️ Update status (Pending → Preparing → Ready → Served)
- 📱 Mobile-first design

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| Flutter | Frontend Framework |
| Firebase Firestore | Real-time Database |
| Firebase Hosting | Web Hosting |
| QR Code | Table Identification |

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed
- Firebase account
- Android Studio / VS Code
